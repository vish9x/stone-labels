# How to print stone labels

## Before you start
- Open `index.html` in **Google Chrome** or **Microsoft Edge**. Double-click the file, or use the link you were sent.
- You need internet, because the app loads its barcode and Excel tools from the web.
- Put the A4 label sheets in the printer tray.

## Print labels for new stock
1. Click **Import Excel / CSV** and choose the stock file (the `.csv` or `.xlsx` export).
   - If the file is wrong, a red message says *"no Stone ID column"*. Choose the right file.
2. Check the count under the buttons, for example *"11 stone(s) to print"*.
   - Only **Available** stones are printed. Tick **Include SOLD stones** only if you need them.
3. If you are reusing a partly used sheet, enter how many labels are already used in **Skip first N labels**.
4. Look at the preview. Each label should show the stone ID, barcode, shape, weight, clarity, measurements, color, lab, and certificate number.
5. Click **Print A4**.
   - In the print window, set **Paper size: A4**, **Margins: None** (or Default), and **Scale: 100%**.
   - Keep **Print cut lines** ticked if you want thin grey lines to cut along. Untick it for a clean sheet.
6. Print one test page on plain paper first and hold it over a label sheet to check the position.

## Clear and start again
- Click **Clear and reset**. This removes the loaded stones and returns all settings to their starting values.
- Use it before importing a different file.

## Do not
- Do not print a sheet without checking the preview first.
- Do not change the **Label width/height** or **Columns/Rows** unless the labels have changed. If they do not match the sheet, the labels will not line up.
- If the preview says *"Labels do not fit on A4"*, the size and count are too large for one page.
